---
title: Keep named tmux sessions per project
date: "2026-06-01"
category: Tech
summary: Attach a named tmux session to each project you're working on — `tmux new -s project-name`. Detach with `Ctrl+B, D` and reconnect from anywhere with `tmux attach -t project-name`. You'll never lose your terminal state between machine switches or SSH sessions.
---

Named tmux sessions are one of the highest-leverage habits in a terminal-heavy workflow.

Instead of opening a pile of unnamed terminals, create one session per project:

```bash
tmux new -s robotics
tmux new -s personal-site
tmux new -s experiments
```

Detach from the current session with `Ctrl+B, D`. List all active sessions with `tmux ls`. Reattach with `tmux attach -t robotics`.

The real payoff comes when you SSH into a remote machine or resume work after a reboot — if your session persists (e.g., on a server or with a session manager like `tmux-resurrect`), your entire workspace — open editors, running processes, split panes — is exactly where you left it.
